## 🎯 What Is This?

**Bingo Mixer** is a mobile-first social bingo game where players find real people who match fun prompts on their card — get 5 in a row to win! 🎉

But this repo is also a **live workshop**: you'll use **VS Code Agent Mode + GitHub Copilot** to redesign, extend, and ship features — guided by AI the whole way.

## 🚀 Quick Start

### Option A — GitHub Codespaces (recommended)

1. Click **[Open in GitHub Codespaces](https://codespaces.new/ron-huberfeld/my-bingo-lab)** above
2. Wait for the container to start — dependencies install automatically
3. Run the dev server:

```bash
npm run dev
```

### Option B — Local Dev Container

1. Clone this repo and open it in VS Code
2. Run **Dev Containers: Reopen in Container**
3. Run `npm run dev`

### Option C — Plain local setup

```bash
# Prerequisites: Node.js 22+
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## 🏗️ Build & Deploy

```bash
npm run build   # production build → dist/
```

Pushes to `main` deploy automatically to **GitHub Pages** via GitHub Actions.

> **Enable Pages:** Settings → Pages → GitHub Actions

## 💡 Tips

1. Keep the live-reloading browser open while coding
2. Commit working code often — use chat *Checkpoints* to revert mistakes
3. Iterate on plans 2+ times before asking the agent to implement
